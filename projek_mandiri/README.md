# Projek Mandiri

Folder ini berisi latihan dan mini-projek C++ yang dikerjakan secara mandiri untuk melatih pemahaman sintaks, struktur data, dan algoritma.

## Aturan Penamaan

- Latihan tunggal: `NNN_nama-latihan.cpp` (contoh: `001_kalkulator.cpp`).
- Projek multi-file: folder `NNN_nama-projek/` dengan titik masuk `main.cpp` dan `README.md` singkat bila diperlukan.

## Cara Menjalankan di PowerShell

```powershell
g++ -std=c++17 -Wall -Wextra 001_nama-latihan.cpp -o app.exe
.\app.exe
```
